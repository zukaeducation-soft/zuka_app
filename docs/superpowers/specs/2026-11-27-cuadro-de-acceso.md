# Entrada a Zuka

Un encabezado azul noche reúne la marca vigente y una esfera trazada con meridianos. Al enfocar el formulario, cambia la orientación de la esfera. La animación respeta la preferencia de movimiento reducido.

El mismo campo acepta un código o un correo. Al escribir un correo aparece la contraseña, con un control para verla y volver a ocultarla. Los errores de formato enfocan el campo que hay que corregir. El botón de entrada indica cuándo se está comprobando la solicitud. Desde la portada se puede cerrar el cuadro para volver.
